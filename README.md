# Flores e Perfumes

Site institucional e catálogo digital da floricultura Flores e Perfumes.

## Tecnologias

- React
- TypeScript
- TanStack Start
- Tailwind CSS
- Vite

## Desenvolvimento

Instale as dependências:

    npm install

Execute o ambiente:

    npm run dev

## Testes

    npm run lint
    npm run test
    npm run build
